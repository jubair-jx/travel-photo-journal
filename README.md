# Travel Photo Journal

A private photo journal: register, verify your email, sign in (optionally with 2FA), and keep a personal collection of travel photos with notes and an auto-generated summary.

> Full documentation lands at submission time. Project docs live in [`docs/`](docs/README.md).

## Layout

| Path       | Purpose                                     |
| ---------- | ------------------------------------------- |
| `apps/api` | Express + TypeScript + Prisma REST API      |
| `apps/web` | Next.js (App Router) + TailwindCSS frontend |
| `docs`     | PRD, architecture, API reference, ADRs      |
